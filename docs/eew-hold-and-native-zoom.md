# 緊急地震速報の予想を最大で持ち続ける・配信 (native) の寄り (v0.23.0)

## A. 緊急地震速報の予想は、同じ地震の間は最大で持ち続ける

### 困りごと (2026-10-01 21:27 千葉県北東部)

同じ地震 (event_id) の第 1〜14 報が、発生から 54 秒〜69 秒の間に出た。
報ごとに予想の地域が出たり空になったりした (第 1・6・7・10 報は地域なし、第 5・8・14 報は千葉県北東部と茨城県南部、など)。
web も配信 (native) も最新の報だけを描くので、震度 4 の地域が点いたり消えたりした。

### 決めたこと

- 取り消しでない同じ地震の報すべてを見て、次の値を持ち続ける。
  - 地域ごとの予想震度: 報ごとの `scale_to ?? scale_from` の最大。
  - 県ごとの予想震度: 県ごとの最大。
  - 予想最大震度 (`max_scale`): 全報の最大。
  - 警報: 一度でも警報の報があれば警報のまま。
- 震源・マグニチュード・発生時刻・報の番号・受信時刻は最新の報のもの。
- 取り消しの報が最新なら、今まで通りその地震を消す。
- 実装は 1 か所の純粋な関数にする。
  - web: `heldForecast(events)` (web/src/groups.ts)。`latestEew` がこれを返すので、一覧・詳細・地図・履歴の再生がそのまま使う。
  - native: `held.rs` の関数を `latest_eews` が使う。配信・再現動画が使う。
- 続報で外された地域を薄れさせる表示 (`droppedForecast`、`.dropped`) は、外れること自体がなくなるので消す。
- 観測の震度を予想に重ねる `overlayForecast` は今まで通り。
- 通知・音・警報の帯は、報 1 つずつに反応するものなので変えない。

## B. 配信 (native) の描画にも、震源へ寄るカメラを付ける

web は地震のときに震源へ寄り、S 波の広がりに合わせて引く (web/src/camera.ts、scene.ts)。
native は常に日本全体で、南西諸島の別枠 (docs/nansei-inset.md) を固定で描いている。

### 決めたこと

- 目標の範囲は web の `renderScene` と同じ。
  - 波が広がる間 (発生から 180 秒まで): S 波の半径 (最小 80km、揺れた範囲の一番遠い角か、無ければ 300km まで)。緊急地震速報の予想は、予想の地域の箱を最初から含める。
  - 波が終わったら: `pad(揺れた範囲 ∪ 震央)`。
  - 揺れた範囲は、緊急地震速報なら予想の地域 (A の最大) の外形の和、無い・引けないときは県の本土の外形。
  - 地震情報 (観測) は、観測点が「地域」で届いたものと、観測点に区域が付いているものの区域、無ければ県の本土。
    - native は観測点の区域を引く stations.json を持たないので、web ほど細かく寄らない場合がある。
- 画面の縦横比 (地図の枠) は保ち、範囲は 250ms の時定数で目標へ近づける (指数。コマの時刻の差で進めるので、再現動画の仮の時計でも同じ動きになる)。時計が大きく飛んだときは目標へ一気に移る。
- 寄っている間 (日本全体より拡大している間) は、南西諸島などの別枠を描かない。平時に戻れば出す。
- 地図の枠の外 (上部バー・右パネル) には描かない。文字の大きさは寄っても変わらない。
- 設定
  - 配信: `broadcast.toml` の `zoom` (既定 false)。e2-micro の負荷を測ってから決める。
  - 再現動画: 既定で寄る。`eq-server replay-video --no-zoom` で寄らない。
- 領域の塗りは今まで通り県単位で、細分区域の塗りは native では描かない (箱の計算にだけ使う)。
  そのため native は `areas.geojson` (細分区域) を読む。読めないときは警告を出し、県の箱で寄る。

### 費用

寄っていて目標か波が動く間は、コマごとに地図を描き直す (海・陸・県を新しい拡大で塗る)。
落ち着けば 1 秒ごとに戻る。配信に使うかは、測った結果 (リリースビルドで寄る・寄らないの 1 コマの時間) を見て決める。
