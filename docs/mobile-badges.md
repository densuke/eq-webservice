# スマホで天気の札が重なり、警報の色を隠す問題 (v0.20.6、web だけ)

2026-10-01 の利用者の指摘。

- スマホの画面で eq.fuga.jp を見ると、各地の天気の札が重なる。
- 気象注意報・警報の塗りが札に隠れて、わかりにくいことがある。
- 配信版 (1280x720 で固定) はぎりぎり被らない。

v0.20.4 の測定 (375px 幅) では、札どうしの重なりが今の画面で 4 組、凡例との重なりが 1 つあった。

## 直すこと (web だけ。native の配信は変えない)

1. **重なる札を間引く**
   - 都市に優先の順番を付ける。例: 東京・大阪・札幌・福岡・那覇・名古屋・仙台・広島・新潟・…。順番は担当が決めて、理由をコメントに残す。
   - 優先の高い順に札を置き、先に置いた札・凡例・別枠・案内・時計と重なる札は出さない。
   - 地図の大きさや向き (縦・横)、拡大・縮小が変わったら、置き直す。
   - パソコンの幅 (今は重なり 0) で出る札が減らないことを確かめる。
   - 間引いた都市の点 (白い点) は残す。押せば札を出すかは、今の作りに合わせて担当が決める。
2. **札の地を半透明にする**
   - 下の警報・注意報の塗りが透けて見えるようにする。
   - 文字が読める濃さを保つ (目安: 地の不透明度 0.75〜0.85)。暗い背景・明るい背景の両方で見る。
3. **設定に「天気の札を出さない」を足す**
   - 既存の「天気の札の切り替え」の設定に、選択肢として足す。
   - 出さないときは、案内 (現在の天気 / 明日の天気) も出さない。
4. テスト (node --test)
   - 間引きの判定を純粋な関数にする (札の四角の並びと優先の順番 → 出す札)。
   - 重ならない並びは全部出す。重なる並びは優先の低いほうを出さない。
5. 確かめ方 (組み込みのブラウザ)
   - 375px (スマホ縦)、812px (スマホ横)、1440px (パソコン) で、今と明日の両方を見る。
   - 札どうし・凡例との重なりの組の数を、v0.20.5 と比べて報告する。
   - 警報の塗りが札の下で透けて見えることを、スクリーンショット (本番に警報が無ければ、手元の `/api/warnings` の仮の値) で確かめる。
