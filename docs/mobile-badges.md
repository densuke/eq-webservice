# スマホで天気の札が重なり、警報の色を隠す問題 (v0.20.6、web だけ)

2026-10-01 の利用者の指摘。

- スマホの画面で eq.fuga.jp を見ると、各地の天気の札が重なる。
- 気象注意報・警報の塗りが札に隠れて、わかりにくいことがある。
- 配信版 (1280x720 で固定) はぎりぎり被らない。

v0.20.4 の測定 (375px 幅) では、札どうしの重なりが今の画面で 4 組、凡例との重なりが 1 つあった。

## 直すこと (web だけ。native の配信は変えない)

1. **重なる札を間引く**
   - 都市に優先の順番を付ける。例: 東京・大阪・札幌・福岡・那覇・名古屋・仙台・広島・新潟・…。順番は担当が決めて、理由をコメントに残す。
   - 優先の高い順に札を置き、先に置いた札・凡例・別枠・案内・時計と重なる札は出さない。
   - 地図の大きさや向き (縦・横)、拡大・縮小が変わったら、置き直す。
   - パソコンの幅 (今は重なり 0) で出る札が減らないことを確かめる。
   - 間引いた都市の点 (白い点) は残す。押せば札を出すかは、今の作りに合わせて担当が決める。
2. **札の地を半透明にする**
   - 下の警報・注意報の塗りが透けて見えるようにする。
   - 文字が読める濃さを保つ (目安: 地の不透明度 0.75〜0.85)。暗い背景・明るい背景の両方で見る。
3. **設定に「天気の札を出さない」を足す**
   - 既存の「天気の札の切り替え」の設定に、選択肢として足す。
   - 出さないときは、案内 (現在の天気 / 明日の天気) も出さない。
4. テスト (node --test)
   - 間引きの判定を純粋な関数にする (札の四角の並びと優先の順番 → 出す札)。
   - 重ならない並びは全部出す。重なる並びは優先の低いほうを出さない。
5. 確かめ方 (組み込みのブラウザ)
   - 375px (スマホ縦)、812px (スマホ横)、1440px (パソコン) で、今と明日の両方を見る。
   - 札どうし・凡例との重なりの組の数を、v0.20.5 と比べて報告する。
   - 警報の塗りが札の下で透けて見えることを、スクリーンショット (本番に警報が無ければ、手元の `/api/warnings` の仮の値) で確かめる。

## 2. v0.20.7: 引き出し線で海の上に逃がす

v0.20.6 をスマホ (縦) で見た利用者の意見 (2026-10-01 12:35 のスクリーンショット)。

- 大阪・神戸の点はあるのに、どちらの札も出ていない。
- 千葉はともかく、神戸は出てほしい。
- 重なるときは、線を引いて海上に出すのでもよい。

直すこと (web だけ):

1. **置き場所を探す**
   - 札は、優先の高い順に、まず今の位置 (向きの表の位置) に置く。
   - 重なるときは、点の周りの別の位置を試す。
     - 候補: 8 方向 × 距離 2〜3 段など。海の上 (陸の塗りに重ならない位置) を優先する。
   - 今の位置から動かした札には、点から札の縁まで細い線 (引き出し線) を引く。
     - 線の色・太さは、札の縁に合わせて目立ちすぎないものにする。
   - どの候補にも置けないときだけ、間引く (v0.20.6 と同じ)。
   - 重ならない相手は、v0.20.6 と同じ。札どうし・凡例・別枠・案内・時計。
2. **パソコンの幅** (今は全部出て重なり 0) では、札の位置を今と変えない。
   - 動かすのは、重なるときだけ。
3. **判定は純粋な関数にする** (札の四角の大きさ・点の位置・候補の位置・ふさがっている四角 → 置き場所と線)。
   - 陸の判定は、地図の塗りの形を使うか、海の位置の簡単な目安 (例: 点から海の方向) を都市ごとに持つかを担当が決める。
   - 判定が重くならないようにする。描き直しのときに 1 回だけ回す。
4. テスト
   - 重ならない並びは動かさない。
   - 重なる並びは低い優先の札を候補の位置へ動かし、線を返す。
   - 置けないときだけ出さない。
5. 確かめ方 (組み込みのブラウザ)
   - 375px・812px・1440px、今と明日。
   - 出る札の数、重なりの組の数、動かした札の数を v0.20.6 と比べる。
   - **375px で大阪と神戸の札がどちらも出ること。**

## 3. v0.23.1: 警報の塗りを札で隠さない (web と配信)

2026-10-02、北海道石狩市に気象警報が出ていたとき、札幌の天気の札 (アイコンと気温) が石狩の上にかかり、警報の塗りの大半を隠していた。注意報は札の下に透けてよいが、警報以上 (警報・危険警報・特別警報) は札より優先して見せる。

1. 札の四角が警報以上の区域と重なるときは、v0.20.7 と同じ候補 (8 方向 × 3 段) から、警報以上の区域に重ならない位置へ動かし、点から引き出し線を引く。点そのものは動かさない。
2. 警報以上の区域は、ほかの札・凡例・別枠・案内・時計と同じ「札を置けない場所」として扱う。注意報は今まで通り (透ける)。
3. 警報以上の区域との判定は、web は札の四角の数点を区域の塗りに当てて調べ、配信は区域の外接矩形の中の点を多角形に当てて調べる。置き直すのは、警報の内容か札の配置が変わったときだけで、毎フレームは回さない。
4. どの候補も塞がっているときは、札を隠さず元の位置に残す (警報が見えにくいのは今と同じ)。
5. 警報が無いときは、札の位置は今までと全く変わらない。
