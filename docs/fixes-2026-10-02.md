# 2026-10-02 の手直し 3 つ (v0.22.2)

2026-10-02 の未明に見つかった 3 つの不具合の直し方。

## A. 明日の天気に気温・降水確率が出ない時間帯

- 気象庁の予報の JSON (`bosai/forecast/data/forecast/{office}.json`) は、0 時から 5 時ごろまで、前日 17 時発表のものが最新になる。
- このとき「明日」(今日の次の日) は、発表から見ると「あさって」にあたる。
  - [0] (短期予報) の天気は明日の分があるが、気温 (timeSeries[2]) と降水確率 (timeSeries[1]) は発表の明日までで終わる。
  - 結果として `temp_min`・`temp_max`・`pop` が無しになり、web と配信にはアイコンだけが出ていた。
- 直し: `parse_forecast` で、[0] に値が無いときは同じ JSON の [1] (週間予報) で補う。値ごとに見る。
  - 降水確率: `[1].timeSeries[0]` の `areas[0].pops` のうち、明日の日付 (timeDefines は 1 日ごと) の値。
  - 最低・最高気温: `[1].timeSeries[1]` の `areas[0].tempsMin`・`tempsMax` のうち、明日の日付の値。
  - 空文字 "" は取れていない値で、無しのままにする。
  - [0] に値があればそちらを先に使う。
- 配信 (native) も同じ `Tomorrow` を使うので、直すのはこの 1 か所だけ。

## B. 画面に変化が出る報ごとに音を鳴らす

- 例: 2026-10-02 04:05 のトカラ列島近海の地震 (履歴の再生)。
  - 緊急地震速報 (予報) の 1 報目は震度不明 (-1)、2 報目以降は最大震度 3。
  - そのあと地震情報の震度速報・震源に関する情報・各地の震度が届く。
  - 今は、震度速報が緊急地震速報で鳴らした扱いになって鳴らず、震度が上がっても鳴らなかった。
- 新しい規則 (web の `alertLevel` と動画の `alert_level` で同じ):
  - 緊急地震速報 (訓練・取消は今まで通り除く)
    - 最初の報と、予報から警報に上がった報: 今まで通り (警報は strong、予報は震度で分ける)。
    - それ以外: 同じ地震のそれまでの報の最大震度より大きくなったときだけ、新しい最大震度で鳴らす。震度不明 (-1) は、分かっている震度より小さいものとして扱う。
  - 地震情報
    - 最初の報で、同じ地震の有効な緊急地震速報が無い: 今まで通り震度で鳴らす。
    - 最初の報で、緊急地震速報が既に鳴らしていた: 案内音 (info)。
    - 最初でない報: 種類によらず案内音 (info)。
- 3 秒以内に続けて鳴らすときは強い音だけ、は今まで通り。
- トカラの並びでは、緊急地震速報 1 報目は無音、2 報目は震度 3 に上がるので medium、3〜6 報目は無音、震度速報・震源・各地の震度はそれぞれ info になる。

## C. 画面の寄りが県の本土の箱になる

- `scene()` は揺れた県の本土の外形 (`prefBox`) で画面を寄せていた。
- 離島だけが揺れた地震 (十島村など) では、鹿児島県の九州本土と震央を枠に入れてしまい、揺れた島が端に小さく出ていた。
- 直し: 揺れた地震情報細分区域の外形で寄せる。
  - 区域の箱は、区域のすべての輪から作る (十島村のように小さな島が多い区域は、本土の輪だけでは 1 つの島しか囲めない)。
  - 区域の外形がまだ読めていない、または名前が引けないときは、今まで通り県の箱にする。
- 本土の地震でも、県全体ではなく揺れた区域の和で寄るので、寄り方が少し締まる (見た目が変わる)。
