レイアウト定義プレビュー 試作

画面の構成をコード (定義) で書き、ブラウザの実際のレイアウト計算でそのまま描きます。定義は右の欄で書き換えて「反映」できます。画面サイズを入れて「サイズから選ぶ」を押すと、定義の when (幅・高さの条件) からプロファイルを選びます。

試す: 1440×900 / 844×390 / 390×844 / 1280×720。重ね物どうしが重なると赤枠と警告が出ます

箱の中の数字は、描いた結果の大きさ (px) と、画面に対する割合です。重ね物 (オレンジ系) は地図などの上に、隅から積んで置きます。小笠原の別枠や通知のように、実際は条件つきで出るものも、ここでは常に描いています。

定義 (JSON)

書式

ノード = 容器 { dir: "row" | "column", size, children: [ノード…], overlays? }
       | 部品 { slot: 部品の名前, size, overlays? }
size   = "fill" (残りを分ける。"fill:2" は重み 2) | "70%" | "380px" | "auto" (部品の中身の大きさ) | "60vh"
overlays = { "top-left" | "top-right" | "bottom-left" | "bottom-right" | "top" | "bottom":
             { flow: "column" | "row", items: [部品の名前 | 入れ子の重ね方…] } }
when   = { minWidth?, maxWidth?, minHeight?, maxHeight?, target?: "broadcast" }   プロファイルを選ぶ条件 (上から順に最初に合うもの。配信用は大きさでは選ばない)
sizes  = { 部品の名前: { w?, h? } }   このプロファイルだけ部品の大きさを変える (0 で出さない)

部品の一覧と既定の大きさは layout-def.js の LD_COMPONENTS。それぞれ、いまの web の要素 (dom) との対応も持っています。
