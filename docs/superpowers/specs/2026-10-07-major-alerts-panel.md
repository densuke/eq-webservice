# 配信の重大な警報の枠 (仕様案)

2026-10-07。Issue #179 の本体。前段 (地震の画面の帯に大津波警報・津波警報・特別警報を出す、PR #183、v0.42.0) の次に作る。前段で入った `Scene::tsunami` (現在の津波予報区) と `native/quake_band.rs` の抽出・順序・色の判断を再利用する。

## 決めたこと (ユーザーと確認済み)

- **出す画面**: 平時も地震の画面も。該当があるときだけ現れ、無いときは今の並びのまま。
- **対象**: 大津波警報・津波警報、気象の特別警報 (大雨・暴風・波浪・高潮・大雪・暴風雪)。津波注意報・緊急地震速報・通常の気象警報は対象外。
- **中身**: 種別ごとに見出しと対象区域の一覧。入りきらなければ帯と同じ置き換え式のページ送り (8 秒)。
- **置き場所**: 右の列の「履歴」の矩形と置き換える。サブの地図・詳細・お知らせ・出典はそのまま。
- **主の地図**: 津波の予報区の海岸線を、等級の色で塗る (web 版の tsunami-line と同じ見た目)。

## 作り

### データ

- 津波: 配信が既に受けている `EventBody::Tsunami` (予報区ごとの等級)。発表中の最新の報を使い、解除 (cancelled) または等級が注意報以下だけになったら枠から消す。判断は web/src/tsunami.ts と同じ規則にする (model.rs の tsunami_rank と揃える)。
- 特別警報: 平時の帯が使う気象警報のデータの `WarningLevel::Emergency` の区域。
- 海岸線の形: web/public/tsunami.geojson (予報区ごとの線)。配信の地図データと同じく、バイナリに埋め込む。

### 部品とレイアウト

- 新しい部品 `alerts` は作らず、**履歴の矩形 (Placed::history) の中身を差し替える**。レイアウトの定義は変えない (web の SLOTS も変えない)。
  - 理由: 「該当があるときだけ現れる」部品はレイアウトの定義では表せない (大きさが固定)。差し替えなら定義側の変更が要らない。
- 枠の見出しの帯の色は最も重い種別に合わせる (大津波警報 > 津波警報 > 特別警報)。配色は前段 (地震の画面の帯) と同じものを使い、新しい色は作らない。
- 1 行の高さ・文字の大きさは履歴の行 (52px) を基準に、区域名は折り返して詰める。

### 地震の画面の帯

- **帯 (banners) は両画面とも残す** (2026-10-07 決定)。定義から外すと平時と地震の画面で主の地図の位置が 50px ずれるため。
- 帯の中身は v0.42.0 のまま変えない (地震の画面では大津波警報・津波警報・特別警報の要約)。枠は同じ内容の詳しい一覧で、帯は目を引く見出し、枠は区域の一覧という分担にする。

## 確かめること (受け入れ)

- PNG の書き出しで、平時 + 大津波警報、平時 + 特別警報、地震の画面 + 津波警報 (サブの地図あり)、平時 + 該当なし (今と同じ絵) の 4 枚。
- 該当なしの絵が main と画素単位で一致すること (平時・地震の画面とも)。
- 海岸線の塗りが、web 版の同じ報 (デモの tsunami.json) と同じ区域であること。
- 判断 (対象の抽出・並び・色・ページ割り) は純粋な関数でテスト。

## 今回やらないこと

- web 版への同じ枠の追加 (配信で形が固まってから)。
- 元の #179 の「県ごとの気象警報の一覧」と、帯を要約に変える件 (重大な警報の枠のあとに改めて決める)。
- 津波の到達予想時刻・高さの表示 (データの有無を調べてから)。
