# 揺れの広がりの再現 (配信) (仕様)

2026-10-18。配信 (native) だけ。web の地図は後で同じ規則を移す (今回は変えない)。

観測点ごとの震度 (各地の震度に関する情報) は地震の数分後に届くため、揺れている最中に観測点を反応させることはできない (強震モニタは利用条件から使わない。調査は Obsidian の「強震モニタ利用条件と揺れのデータ源の調査」)。そこで、観測点の値が届いた時点で、発生時刻から P 波・S 波の円を描き直し、S 波の円の縁が届いた観測点から順に灯す「揺れの広がり (再現)」を 1 回流す。新しいデータ源は使わない。

## 決めたこと (ユーザー確認済み)

### いつ流すか

- 流す報: 地震のまとまり (`model::group_quakes`) の中で、観測点 (区域ではない点、`!is_area`) を初めて含んだ報 (ふつうは「各地の震度に関する情報」)。その報の時点のまとまりの最大震度が 3 以上のときだけ。
- 同じ地震のそれ以降の報 (訂正・続報) では流し直さない。
- 開始: 流す報の受信時刻 R の 2 秒後を、再現の発生時刻 0 秒とする (`LEAD_MS = 2_000`)。R から開始までの 2 秒は、点を全部隠して案内だけを出す。
- 速さは等倍。

### 止めるとき

- 一番遠い点に S 波が届いてから 5 秒で終わる (`HOLD_MS = 5_000`)。終わったら今までどおり全部の点を出した表示。
- 長さの上限は今の波と同じ 180 秒 (`WAVE_MAX_MS`)。
- 再現の最中に、緊急地震速報、または別の地震 (`same_quake` でない) の地震情報が届いたら、その時点でやめる。ライブの情報を優先する。同じ地震の続報では止めない。
- 地震の画面がその地震でない (`eew::current` が別の地震・平時) ときは流さない。

### 描くもの

- 地震の画面はそのまま (寄り・右のパネル・都道府県の塗り・震度の札は今と同じ)。
- 波: 震央と深さはその地震の地震情報 (無ければ `DEFAULT_DEPTH_KM`)、起点は再現の発生時刻。円は今の `surface_radius_km` (P 波 `VP_KM_S`、S 波 `VS_KM_S`) で描く。サブの地図にも同じ波を映す (今の `sub_wave` と同じ扱い)。
- 観測点の点: S 波の地表での半径が、その点の震央距離以上になった点だけ描く。点と円は同じ `surface_radius_km` を使うので、点が円より先に灯ることはない。
- 点の絞り込みは、画面の止まった部分 (still) の描き直しで行う。地震の画面のあいだ still は毎秒描き直しているので、点の増え方は 1 秒刻み。1 秒で S 波は約 4km 進む。点が円の縁より遅れるのは最大 1 秒で、先に出ることはない。
- 案内: 再現のあいだ、本図の右上に「揺れの広がり (再現)」の文字を出す (既存の文字色 `TEXT`、13px。左上は南西諸島の別枠と重なるため)。
- 音・読み上げは鳴らさない。報が届いたときのチャイム・読み上げは今のまま。

## 作り

- `native/spread.rs` (新規。純粋な関数):
  - `Spread { lat, lon, depth_km, start_ms, end_ms }`
  - `spread_of(events, current: &QuakeSummary, zones: &Zones, now_ms) -> Option<Spread>`: 流す報を探し、止める条件を見て、いま再現の最中なら返す。再現の窓 (受信から `LEAD_MS` + 180 秒) の外は、点の計算をせずにすぐ返す (地震の画面のあいだ毎コマ呼ばれるため)。
  - `reach_km(spread, now_ms) -> Option<f64>`: S 波の地表での半径 (開始前は None = 点を全部隠す)。
  - `wave(spread, now_ms) -> Wave`: 描く円。
  - 終わりの時刻: 流す報の観測点のうち一番遠い点の震央距離から、S 波が届く時刻 + `HOLD_MS`。
- `step.rs`: `spread_of` を求め、最中なら `frame_waves` の波に再現の波を加え (同じ地震の今の波は出さない)、`Scene` に `spread` を渡す。still_key は変えない (still は毎秒描き直しているので、点は 1 秒刻みで増える。描画の部の「点の絞り込み」のとおり)。
- `draw.rs`: `Shake::of` で、`spread` があれば点を `reach_km` で絞る。案内の札を描く。
- `look` (記録の描き直しの音と終わりの判断) は再現の波を数えない。数えると、記録の描き直しで波の間に鳴らす刻みの音が再現の間にも鳴るため (音は鳴らさない)。記録からの再現動画でも、描画には再現が出る。

## 確かめること

- 純粋な関数のテスト (`spread.rs`):
  - 最大震度 3 以上で観測点が初めて入った報から流れる。2 以下・区域だけの報では流れない。続報では流し直さない。
  - 開始前は点を全部隠し、S 波の円の内側の点だけが灯る (円の外の点は灯らない)。
  - 一番遠い点に届いて 5 秒で終わる。180 秒を超えない。
  - 緊急地震速報・別の地震の報が届いたら止まる。同じ地震の続報では止まらない。
- 重さ: `dots_bench` (能登 2024-01-01) で、再現の最中の 1 コマの重さを測る。
- 目視: 能登の記録で、再現の途中の数コマを PNG に書き出して確かめる。
